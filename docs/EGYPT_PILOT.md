# خطة التشغيل التجريبي — مصر

## النطاق المعتمد
- دولة الاختبار الأولى: مصر.
- أنواع مقدمي الخدمة: مستشفيات، عيادات، أطباء.
- اللغات: العربية والإنجليزية.
- مصادر الإدخال: الإدارة ومقدمو الخدمة.
- كل بيانات مقدمي الخدمة تمر بمراجعة قبل ظهورها كبيانات معتمدة.

## استراتيجية البيانات
1. ابدأ ببيانات مقدمي الخدمة الذين يسجلون مباشرة ويوافقون على نشر بياناتهم.
2. أضف مصادر حكومية/مهنية أو أدلة مرخصة فقط بعد التحقق من شروط إعادة الاستخدام.
3. لا تعتمد على نتائج الخرائط وحدها لإثبات الترخيص الطبي أو صحة المواعيد.
4. احتفظ بمصدر كل معلومة وتاريخ آخر تحقق وهوية المراجع.
5. وفر للمستخدم زر «الإبلاغ عن معلومة غير صحيحة».

## مناطق التوسع داخل مصر
تُضاف المحافظات والمدن تدريجياً بعد اختبار جودة البيانات، مع دعم البحث باسم المحافظة والمدينة والحي، وإدخال يدوي للموقع إذا لم يمنح المستخدم إذن GPS.

## تحقق مقدمي الخدمة
- الطبيب: الاسم المهني، التخصص، جهة/رقم القيد المهني عند الاقتضاء، مستندات إثبات مناسبة.
- العيادة/المستشفى: الاسم القانوني أو التجاري، العنوان، وسيلة اتصال يمكن التحقق منها، ومستندات الترخيص عند الاقتضاء.
- لا تُعرض شارة «تم التحقق» قبل إتمام مراجعة بشرية موثقة.
- لا تجمع مستندات أكثر مما يلزم، وقيّد الوصول إليها واحذفها وفق سياسة احتفاظ معلنة.

## المواعيد
تمييز واضح بين:
- ساعات العمل المعلنة.
- أوقات استقبال الاتصالات.
- مواعيد متاحة للحجز فعلياً.
لا تعرض حجزاً مؤكداً إلا إذا أكد مقدم الخدمة الحجز أو أعادت واجهته نتيجة حجز موثوقة.

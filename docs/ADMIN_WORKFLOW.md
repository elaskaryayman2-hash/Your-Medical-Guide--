# سير عمل الإدارة ومقدمي الخدمة

## الأدوار
- زائر: البحث وعرض البيانات العامة والاتصال.
- مقدم خدمة: إنشاء ملف وطلب ملكية ملف موجود وإرسال تعديلات.
- مراجع: مراجعة البيانات والمستندات والمصادر.
- مدير: إدارة المستخدمين والأدوار والدول والتخصصات والإعدادات.

## دورة حياة السجل
`draft -> pending_review -> approved -> published`
وحالات بديلة: `rejected`, `needs_changes`, `suspended`.

لا يغيّر مقدم الخدمة السجل المنشور مباشرة؛ يرسل نسخة تعديل منفصلة للمراجعة. يجب تسجيل من غيّر ماذا ومتى ولماذا.

## قائمة التحقق قبل النشر
- الاسم ونوع المنشأة صحيحان.
- العنوان والمدينة والدولة محددة.
- رقم الهاتف بصيغة دولية ويمكن الاتصال به.
- ساعات العمل تتضمن المنطقة الزمنية وتاريخ آخر تحديث.
- مصدر البيانات وحق استخدامها موثقان.
- التخصصات والخدمات ليست مضللة.
- وثائق التحقق المطلوبة راجعها شخص مخوّل.
- لا توجد بيانات شخصية أو صحية للمرضى ضمن الملف العام.

## إدارة الشكاوى والتصحيح
يستطيع المستخدم الإبلاغ عن هاتف خاطئ أو عنوان مغلق أو بيانات قديمة. تُفتح تذكرة مراجعة ولا تُحذف البيانات تلقائياً إلا عند وجود سبب أمني/قانوني واضح.
